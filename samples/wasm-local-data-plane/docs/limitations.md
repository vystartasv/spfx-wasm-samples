# Limitations and rejected assumptions

- M1 has deterministic mock Graph, SharePoint, CRM, and enterprise adapters; it has not validated a tenant, permissions, CSP, cross-origin isolation, OPFS quotas, browser matrix, or real Graph/SharePoint batch behavior.
- OPFS is preferred only when the worker context exposes the package's OPFS support and the required browser primitives. Otherwise the UI shows `memory`; memory data is lost when the worker is recreated.
- The official package's documented Node path is in-memory only. The real browser OPFS path requires deployment headers and is not proven by the Node test.
- No performance number, tenant compatibility, scalability limit, or sync completeness claim is made. The evidence table remains pending until a controlled run is recorded.
- Conflict resolution is surfaced, not auto-merged. Retry classification is explicit; exponential backoff, resumable real transport, and service-specific auth are future work.
- We reject distributed-ACID wording, cache-as-security wording, threshold-bypass wording, and the assumption that an opaque cursor can safely be parsed or regenerated by the local store.
