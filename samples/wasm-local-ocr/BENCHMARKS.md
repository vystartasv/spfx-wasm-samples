# Benchmarks

No performance number is claimed without a browser run. The UI reports measured elapsed time for each completed recognition and the input byte count. Timing includes engine startup on the first run and excludes selection time.

Measure the fixture and representative tenant images in the target browser/device. Compare first run (cold worker/model cache) with a second run (browser cache). OCR accuracy is image- and language-dependent; this sample does not convert confidence into a correctness claim.
