# Benchmark methodology

This sample does not publish timings. To measure it, run the web part in the target browser, click **Hydrate fixture**, then use the UI search/filter/sort controls and record browser Performance timings around each action. Repeat after **Reset / clear**, record whether status reports `opfs` or `memory`, browser/version, SPFx version, fixture state, and any console or worker errors. Compare only runs with the same fixture and query.

The displayed counts and timestamps are from the current run. No benchmark numbers, tenant results, or persistence claims are seeded.
