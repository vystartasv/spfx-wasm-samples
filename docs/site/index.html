The reference pattern

Keep the engine behind a contract.

TypeScript owns UI, validation, cancellation, accessibility, and host integration. A dedicated worker owns expensive or stateful work and returns a shaped result.

01

Worker by default

Expensive or stateful engines stay off the UI thread, with cancellation and cleanup visible in the contract.

02

Baseline first

Every WASM experiment names a native or no-engine baseline. A package is not a performance conclusion.

03

Failure is a result

Actual engine, fallback, warning, and error states remain inspectable instead of being hidden by the demo.

04

Network is opt-in

Bytes stay local by default. SharePoint writes require an explicit UI action and a metadata declaration.
