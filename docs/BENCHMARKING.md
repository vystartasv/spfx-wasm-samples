# Benchmarking

Benchmarks compare the complete user task with the named native baseline. Record fixture, browser, device, input size, cold or warm state, engine, elapsed time, bytes, memory where available, and warnings. Repeat enough runs to describe variability.

Repository tests prove deterministic contracts; they do not establish browser, tenant, CSP, or generally portable performance evidence. Do not promote a sample’s displayed measurement into a repository-wide claim.
