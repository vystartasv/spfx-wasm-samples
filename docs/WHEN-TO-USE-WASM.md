# When to use WASM

Use it only when all are true: a real workload exists; a suitable engine exists; the native baseline is insufficient or unavailable; the asset and loading cost is acceptable; the security/licensing boundary is understood; and controlled evidence supports the decision.

Do not use it for ordinary UI, small transformations, or speculative scale. Stop when the baseline meets the user need, the engine cannot be packaged safely, or the evidence is only a vendor claim.
