# WASM cost model

Evaluate total task cost: shipped bytes and license; load/fetch/compile; worker startup and message copies; memory and peak input size; main-thread responsiveness; CSP and asset routing; fallback behavior; debugging and browser support; and maintenance of the upstream engine.

Compare the complete user journey with the native baseline. A faster inner loop can still lose on cold load or memory. No repository number generalizes beyond its fixture, browser, device, and run.
