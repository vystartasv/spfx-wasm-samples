# Code of Conduct

We want this project to be a welcoming, respectful, and technically constructive place to contribute.

Expected behavior includes listening, assuming good faith, giving actionable feedback, respecting boundaries, and focusing criticism on ideas and code rather than people. Harassment, discrimination, threats, doxxing, sexualized behavior, and unwanted contact are not acceptable.

Report conduct concerns privately through the repository's GitHub support mechanisms or open an issue when a public report is appropriate. Do not include sensitive personal information in a public issue.
