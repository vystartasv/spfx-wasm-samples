# Security policy

The technical WASM security model is documented in [docs/SECURITY.md](docs/SECURITY.md). This root file covers vulnerability reporting only.

This repository contains educational SPFx samples. Local browser storage, worker isolation, namespace fields, and sample adapters are not security boundaries and do not replace SharePoint/Graph authorization, tenant policy, Conditional Access, encryption, or server-side controls.

Please do not report vulnerabilities with secrets, tokens, tenant exports, or other sensitive data in a public issue. Use [GitHub Security Advisories](https://github.com/vystartasv/spfx-wasm-samples/security/advisories/new) when available. If an advisory cannot be opened, use a [GitHub issue](https://github.com/vystartasv/spfx-wasm-samples/issues) with the minimum non-sensitive detail needed to request private follow-up.
